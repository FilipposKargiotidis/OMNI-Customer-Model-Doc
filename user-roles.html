Access management

External User Roles

Roles describe what an external user can do in Merchant Portal. Their effective access also depends on the account or organizational scope to which they are assigned.

Role descriptions

Each role describes a different set of responsibilities. The account or organizational scope assigned to the user also affects their effective access.

A
ADMINISTRATION

Administrator

Has broad access to Stores and application features within the assigned organizational scope. Administrators manage user accounts, have authority over financial transactions, and can create access tokens and update company name or host URL. The presentation describes assigning the same email to access multiple Companies or Stores.

Scope: The source describes administrator access at Corporation, Company and Store levels.
F
FINANCIAL OPERATIONS

Finance

Reviews and approves financial transactions, including capture, refund and cancellation under the applicable rules and policies. Finance users can access audit logs and report documents such as invoices and settlements, download documents, and create payment links.

Limitation: The presentation says Finance users cannot add or remove users.
S
CUSTOMER ASSISTANCE

Support

Assists customers with financial and transaction-related questions. Support users can view transactions, investigate issues, provide guidance and create payment links.

Limitations: The presentation says Support cannot add or remove users and cannot perform reversals or refunds.
T
TECHNICAL ACCESS

Technical

Supports technical access by creating and managing access tokens and updating company name or host URL. The presentation also describes transaction administration for integration testing.

Limitation: The presentation says Technical users cannot add or remove users. Confirm the precise transaction-testing permissions before production use.
R
READ-ONLY ACCESS

Reader

Views transaction data and related information for analysis, without changing or administering transactions. Reader users cannot export data.

Limitations: The detailed role slide says Readers cannot add users, administer transactions, export data or directly view audit logs.
These descriptions summarize the supplied presentation. Use the Role Permission Matrix alongside this page; some activities in the descriptions and matrix need reconciliation.
