Test Store (Online)

Test Stores support customer integration work for Pay online services, allowing eCommerce flows to be exercised without processing live customer payments.

How Test Stores work

Test Stores are currently used internally to support testing of Pay online services.

TEST
ENVIRONMENT BOUNDARY

Portal setup, simulated transactions

Test Store setup is handled internally in the production Merchant Portal. Transactions use the ECOM external integration and are simulated for testing; they are not live customer payments.

Capabilities that exist today

The current internal setup supports testing with simulated transactions. Creating an Online Test Store automatically creates its Pay online contract; the internal integration team then configures the payment methods to be tested. This is not yet a self-service capability for external customers.

Available internally

Internal Test Store setup

Internal teams can set up Test Stores through the production Merchant Portal.

Created automatically

Pay online contract

When an Online Test Store is created, its Pay online contract is created automatically.

Manual internal step

Payment method configuration

The internal integration team configures which payment methods are available for testing on the Test Store.

Test transactions

ECOM external integration

Transactions generated for a Test Store are simulated through the ECOM external integration and are not live payments.

Implemented

SCM and Search

Test Stores are supported in SCM and Search, including Store operations, indexing, and retrieval.

Implemented

Customer API test mode

The Customer API supports test-mode behavior for Test Stores, allowing test requests and responses to be validated without treating transactions as live payments.

Further capabilities to explore

The following customer-facing capabilities remain in the proposed scope; they should not be read as already available to customers.

01

Customer Test Store setup

Customer-facing Test Store creation and management have not been developed or made available yet. The future goal is to provide customers with a clear, seamless self-service setup experience.
